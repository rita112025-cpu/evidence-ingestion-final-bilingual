    06 LIMITATIONS

    Hash ≠ Truth - verifies integrity, not truthfulness.
    Timestamp ≠ Authenticity
    Derived ≠ Original
    System ≠ Legal chain-of-custody

    Hash 可驗證檔案完整性，但不能證明來源內容本身為真。
