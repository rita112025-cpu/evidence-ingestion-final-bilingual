MarkItDown / 文件擷取

MIT~122k starsLLM Ready

Microsoft MarkItDown: converts Office, PDF, images, audio into clean Markdown structure optimized for LLM ingestion. Keeps headings, tables, lists. MIT license, ~122k stars.

  • Input: docx, xlsx, pptx, pdf, jpg, mp3, html
  • Output: structured Markdown for LLM context
  • Use for evidence: preserve original structure

Crawl4AI / 網頁轉檔

Apache-2.0~83.4k starsFirecrawl: AGPL-3.0 core / MIT SDK ~166k

Crawl4AI: open-source LLM-friendly crawler, Apache-2.0, ~83.4k stars. Async, markdown output, JS rendering, chunking.

Firecrawl: alternative, AGPL-3.0 for core service, MIT for SDKs, ~166k stars. Cloud + self-host, handles anti-bot.

  • Best for: single-page to markdown evidence
  • Compare: Crawl4AI self-host first, Firecrawl managed first

Browser Use: MIT ~112k stars. LLM agent that controls browser to click, fill, navigate, extract. Connects vision + DOM.

  • Use when login, pagination, interaction needed
  • Produces trace + screenshots as evidence

Scrapy Stack / 大量爬蟲

Scrapling BSD-3-Clausescrcpy ~149.9kTLS Fingerprint

For scale: Scrapling (BSD-3-Clause) – modern Scrapy alternative with better anti-bot handling. scrcpy (~149.9k stars) is Android screen mirroring for mobile evidence, not crawler but useful for app capture. curl-impersonate spoofs real browser TLS fingerprints to bypass WAF. AutoScraper learns rules from examples.

  • Scrapling: light, undetected, sync/async
  • curl-impersonate: solves TLS fingerprint blocks
  • AutoScraper: ML rule learning from sample
