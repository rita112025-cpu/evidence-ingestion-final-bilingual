WHY / 為什麼

EVIDENCE-FIRST

Any tool can summarize a page. Almost none can prove what the page actually said. This system treats the original capture as ground truth, and every transformation as a derived, hash-linked copy — so a claim can always be traced back to its source.

  • Original bytes are captured and hashed before any conversion
  • Derived output (markdown, text) is hashed separately and linked to the original
  • Every record carries a source URL and capture timestamp

PIPELINE / 流程

6 STEPS
1Fetch original (MarkItDown / Crawl4AI / Browser Use)
↓
2Hash original bytes (SHA-256)
↓
3Convert to derived Markdown
↓
4Hash derived output (SHA-256)
↓
5Write evidence record (source, timestamp, both hashes)
↓
6Store under /docs/evidence with an index

CORE TOOLS / 核心工具

MIT
MarkItDown

Converts Office, PDF, images, audio into clean Markdown structure optimized for LLM ingestion. Keeps headings, tables, lists.

Apache-2.0
Crawl4AI

Open-source LLM-friendly crawler. Async, markdown output, JS rendering, chunking.

Browser Use · extension

MIT. LLM agent that clicks, fills, navigates, extracts. Use when login/pagination needed.

Scrapling · extension

BSD-3-Clause. Modern Scrapy alternative with better anti-bot handling, for scale.

Not Core — additional tools
scrcpy

Android screen mirroring. Not a crawler — useful for capturing mobile app evidence.

curl-impersonate

Mimics real browser TLS/HTTP fingerprints to reduce anti-bot blocking during fetch.

AutoScraper

Learns extraction rules from a handful of labeled examples.

Firecrawl

Alternative crawler. AGPL-3.0 core service, MIT SDKs. Cloud or self-host.

LIMITATIONS / 限制

⚠ Read before treating output as legal evidence
  • A hash proves the captured bytes were not altered after capture — it does not prove the source content was accurate, authentic, or unedited before capture.
  • Timestamps come from the local system clock, not a trusted timestamping authority.
  • This system is not a substitute for a formal legal chain-of-custody process.
  • Rendered pages (JS-heavy sites) may differ across browsers, devices, or time — capture what you can, and record how it was captured.
  • Evidence records shown in this demo (EV-0001 to EV-0003) are example data, not real captures.
